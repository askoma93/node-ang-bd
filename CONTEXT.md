# SkillForge

Платформа предоставляет публичный каталог учебных испытаний для любых навыков, которые можно оценить по текстовой работе. Стартовый каталог посвящён разработке ПО; администраторы публикуют испытания, а пользователи выполняют их и получают автоматический результат проверки.

## Language

**Skill**:
Область способности или знания, развитию которой посвящены испытания.
_Avoid_: Category, subject, technology

**Challenge**:
Опубликованное администратором учебное задание с критериями оценки, публично доступное для просмотра без учётной записи. Относится ровно к одному навыку, имеет один уровень сложности и может иметь несколько тегов.
_Avoid_: Exercise, task, course

**Challenge Lifecycle**:
Состояние испытания: Draft, Published или Archived. Черновик можно свободно менять; содержательную часть опубликованного испытания с отправленными работами менять нельзя; архивное испытание скрыто из каталога, но сохраняется в истории пользователей.
_Avoid_: Visibility, progress

**Difficulty**:
Заявленный уровень сложности испытания: Beginner, Intermediate или Advanced.
_Avoid_: Skill level, rank

**Tag**:
Дополнительная метка для поиска пересекающихся тем внутри разных навыков.
_Avoid_: Skill, category

**Evaluation Rubric**:
Набор заданных администратором критериев с названием, точным описанием и максимальным баллом, а также общий проходной процент испытания.
_Avoid_: Prompt, checklist

**Submission**:
Приватная работа в формате Markdown с необязательной внешней ссылкой, которую пользователь отправил в ответ на испытание для автоматической проверки. Количество повторных отправок не ограничено, история сохраняется полностью, а уже достигнутое завершение испытания не отменяется последующими отправками.
_Avoid_: Solution, answer, attempt

**AI Evaluation**:
Окончательная автоматическая оценка отправленной работы, содержащая ограниченный максимальным значением балл и комментарий по каждому критерию. Приложение вычисляет общий процент и вердикт; технический сбой или недопустимый ответ модели не является оценкой и не означает, что пользователь не прошёл испытание.
_Avoid_: Admin review, moderation

**Evaluation Notification**:
Сохраняемое сообщение пользователю о завершении проверки его отправленной работы. Оно остаётся непрочитанным до явного прочтения пользователем, независимо от того, был ли он онлайн в момент проверки.
_Avoid_: Toast, alert

**Challenge Progress**:
Текущее положение пользователя в прохождении испытания: Not Started, In Progress, Evaluation Pending, Needs Revision или Completed. Техническая задержка проверки относится к отправке и не является отдельным учебным статусом.
_Avoid_: Skill level, mastery score

**Skill Progress**:
Количество завершённых пользователем испытаний относительно всех опубликованных испытаний выбранного навыка.
_Avoid_: Mastery, proficiency, rank

**User**:
Участник, который выбирает испытания, выполняет их и просматривает результаты проверки.
_Avoid_: Learner, student

**Admin**:
Участник, который управляет навыками, тегами, испытаниями и критериями оценки, но не проверяет и не читает пользовательские отправки. Может видеть агрегированную статистику и перезапускать технически неудавшуюся проверку без доступа к содержимому работы.
_Avoid_: Teacher, moderator
